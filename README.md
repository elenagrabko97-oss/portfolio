О проекте
В качестве практического задания я тестирую веб-приложение с формой регистрации.
Я прошла следующие этапы:
1. Изучила требования к форме регистрации.
2. Составила чек-лист для проверки функциональности.
3. Создала тест-кейсы в Test IT.
4. Провела тестирование учебной сборки приложения.
5. Нашла дефекты.
6. Оформила найденные дефекты в Jira.
Следующим этапом проекта будет тестирование API в Postman.
Что проверяла
При тестировании формы регистрации проверяла:
* регистрацию с корректными данными;
* пустые обязательные поля;
* корректность email;
* некорректный формат email;
* минимальную длину пароля;
* пароль короче установленного значения;
* различные варианты пользовательского ввода;
* отображение ошибок;
* поведение формы при некорректных данных.
Для проверки использовала позитивные и негативные сценарии.
Найденные дефекты
В процессе тестирования я обнаружила 4 дефекта, которые оформила в Jira.
В баг-репортах указаны:
* заголовок;
* шаги воспроизведения;
* фактический результат;
* ожидаемый результат;
* окружение;
* приоритет и серьёзность дефекта.
Например, были обнаружены проблемы с валидацией:
* регистрация с пустым паролем;
* регистрация с email в некорректном формате;
* регистрация с паролем короче установленного требования.
