# QA Portfolio 

Привет! Меня зовут Елена.

Я изучаю тестирование программного обеспечения и готовлюсь к позиции **Junior QA Engineer**.

В этом репозитории собраны мои практические работы по ручному тестированию.

## О проекте

В рамках практического проекта я тестировала веб-приложение с формой регистрации пользователя.

Во время работы я прошла основные этапы тестирования:

1. Изучила требования к форме регистрации.
2. Составила чек-лист.
3. Создала тест-кейсы в Test IT.
4. Провела тестирование учебной сборки приложения.
5. Нашла дефекты.
6. Оформила найденные дефекты в Jira.

## Что проверяла

В процессе тестирования проверяла:

- успешную регистрацию нового пользователя;
- обязательность заполнения полей;
- регистрацию с пустыми полями;
- корректность формата Email;
- регистрацию с уже существующим Email;
- минимальную длину пароля;
- наличие заглавной буквы в пароле;
- наличие цифры в пароле;
- ограничение длины имени;
- отображение и поведение формы при некорректных данных.

Для проверки использовала позитивные и негативные сценарии.

## Результаты тестирования

В процессе тестирования я обнаружила **4 дефекта** и оформила их в Jira.

Найденные проблемы:

- регистрация выполняется при пустом поле Email;
- регистрация выполняется при пустом поле Password;
- регистрация выполняется с Email без символа `@`;
- регистрация выполняется с паролем менее 8 символов.

Каждый дефект оформлен отдельным баг-репортом с шагами воспроизведения, ожидаемым и фактическим результатом.
