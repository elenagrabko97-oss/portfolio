# BUG-02 — Регистрация выполняется при пустом поле «Пароль»

**Jira:** SCRUM-2
**Статус:** В работе

## Описание

При попытке регистрации с пустым полем «Пароль» форма отправляется, хотя пароль является обязательным полем.

## Шаги воспроизведения

1. Открыть страницу регистрации.
2. Ввести корректное имя.
3. Ввести корректный Email.
4. Оставить поле «Пароль» пустым.
5. Нажать кнопку «Зарегистрироваться».

## Ожидаемый результат

Появляется сообщение об ошибке о необходимости заполнить поле «Пароль». Регистрация не выполняется.

## Фактический результат

Форма отправляется при пустом поле «Пароль».

## Вложения

Скриншот бага находится в Jira.
