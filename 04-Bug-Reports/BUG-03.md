# BUG-03 — Регистрация выполняется с Email без символа @

**Jira:** SCRUM-3
**Статус:** В работе

## Описание

При попытке регистрации с Email без символа `@` форма отправляется, хотя Email указан в некорректном формате.

## Шаги воспроизведения

1. Открыть страницу регистрации.
2. Ввести корректное имя.
3. Ввести Email без символа `@`.
4. Ввести корректный пароль.
5. Нажать кнопку «Зарегистрироваться».

## Ожидаемый результат

Появляется сообщение об ошибке о некорректном формате Email. Регистрация не выполняется.

## Фактический результат

Форма отправляется с Email без символа `@`.
