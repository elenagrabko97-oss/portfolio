# Тест-кейсы формы регистрации

Тест-кейсы созданы в Test IT на основании требований к форме регистрации.

Всего создано **10 тест-кейсов**.

## TC-38 — Успешная регистрация нового пользователя

**Предусловия:**
Открыта страница регистрации. Пользователь с указанным Email ранее не был зарегистрирован.

**Шаги:**

1. Ввести корректное имя.
2. Ввести корректный Email.
3. Ввести корректный пароль.
4. Нажать кнопку «Зарегистрироваться».

**Ожидаемый результат:**
Пользователь успешно зарегистрирован, отображается сообщение об успешной регистрации и выполняется переход в личный кабинет.

**Приоритет:** Средний
**Статус:** Готов
